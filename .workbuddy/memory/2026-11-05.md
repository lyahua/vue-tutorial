## L1 实时推送 bug 修复（用户发现）
- 现象：idc-three L1 的 metrics 订阅后除首帧永远不更新（时钟不走）。
- 根因：mock/runtime.js 的 walk() 只 refresh() 换 snapshot、从不调 listeners —— idcMap 原版同款静默 bug（listeners 只用于定时器生死管理），抄写时一并带入。修复：walk 末尾 `const snap = refresh(); listeners.forEach(fn => fn(snap));`。
- 连带修复：告警 ts 原用 Math.random 偏移——真实推送后列表会每 2.5s 重排跳动，改为 stableSec(rackId) 稳定散列偏移（0~480s）。
- idcMap 原版仍有同款 bug 未动（参考工程，如需同样修复告知）。L1 页面 metrics 双赋值说明：data() 首屏兜底 + subscribe 订阅即推首帧（SSE 语义），非重复。
